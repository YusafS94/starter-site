# 🚀 Modern Dark Mode Starter Site

A lean, high-performance, and responsive dark mode landing page boilerplate. Built with semantic HTML5, modern CSS (Custom Properties, Flexbox, CSS Grid), and lightweight vanilla JavaScript.

This template is designed with zero third-party dependencies, making it the perfect launchpad to quickly prototype ideas, build out components, or practice modern web development techniques.

---

## 🛠️ Features

- **Pure Vanilla Stack:** No frameworks, no heavy libraries, and zero runtime dependencies.
- **Deep Slate Dark Mode:** A premium, eye-friendly dark aesthetic utilizing modern color theory and elevation shading.
- **Fluid Responsive Layouts:** Built mobile-first using CSS Grid and Flexbox architectures that scale seamlessly up to desktop viewports.
- **Full-Screen Mobile Navigation:** A smooth, CSS-transition-powered mobile overlay nav with an animated hamburger toggle.
- **Accessible & Clean:** Semantic markup structured with basic `aria-*` attributes and native layout safety switches (like background scroll-locking).
